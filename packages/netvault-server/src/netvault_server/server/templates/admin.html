Maintenance Actions

Full Library Optimization + DOI Writeback

ALL ELIGIBLE PDFS · PDFCRAFT 150 PPI / Q75

Run the same full-library PDFCraft sweep used on the host: process every PDF not yet marked as optimized, write verified DOI into the compressed PDF when possible, and update PostgreSQL SHA-256, file size and storage path. Previously optimized PDFs are skipped. This does not invent DOI identities or automatically fill Crossref bibliography fields.

.venv/bin/python scripts/compress_pdfs_parallel.py --all --jobs 3

Document Health Audit

Read-only PostgreSQL scan of pending optimization, missing bibliography and DOI health. No PDF bytes or records are changed.

Bibliography Verification

Use DOI registry data and PDF title evidence to propose missing metadata. Only verified fill-only proposals can be approved.

Limited write approvals require a recent verified backup and reviewed document IDs/hashes. The separate full-library command above intentionally creates no backup, and may irreversibly replace source PDFs. Both paths require explicit administrator confirmation. No destructive cleanup or free-form SQL is available here.
